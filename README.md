ضع هذه الملفات في جذر مستودع GitHub الذي فيه مجلد images (بجانبه).
Cloudflare → Workers & Pages → Create → Pages → Connect to Git. Build command: (فارغ)، Output directory: /.
لنموذج التوظيف: أنشئ حسابًا مجانيًا في resend.com وأنشئ API key، ثم في Cloudflare Pages → Settings → Variables أضف: RESEND_API_KEY و TO_EMAIL (بريد الاستلام). للإرسال لأي بريد وبنفس اسم الشركة: وثّق الدومين في Resend وأضف FROM_EMAIL.
بدّل الصور الافتراضية للخلفيات من data-bg في كل صفحة (صيغة المجلد/رقم).
